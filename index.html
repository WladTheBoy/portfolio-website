02

Owl Synth

+

A polyphonic synthesizer that runs entirely in the browser. It generates sound in real time with the Web Audio API and can be played with your computer keyboard or an on-screen piano. Each voice has two slightly detuned oscillators, a low-pass filter and an ADSR envelope, with a soft-feedback delay for a floating sound. Waveform, detune, filter, envelope and delay are adjustable live, and an oscilloscope visualizes the signal.

The audio engine is written in TypeScript and kept separate from the React UI, with unit tests in Vitest and a CI pipeline on GitHub Actions. Inspired by the synths and sounds of Adam Young, a.k.a. Owl City.

TypeScriptReactWeb Audio APIViteBunVitestGitHub Actions
